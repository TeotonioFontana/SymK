# FP-001 --- Validation Protocol

## Purpose

Describe how engineering evidence evolves SymK.

## Validation Project

LexBrain.

## Return Criteria

-   Modeling contradiction.
-   Missing primitive.
-   Vocabulary limitation.
-   Repeated conceptual split or merge.

## Non-Criteria

-   Naming.
-   UI.
-   Coding style.
-   Convenience.

## Cycle

SymK → LexBrain → Evidence → SymK
