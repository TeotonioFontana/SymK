# SymK Knowledge Candidate Corpus

**Status:** Candidate and source-evidence workspace
**Authority:** No independent normative or canonical effect

This tree contains imported sources, curation work, candidate canonical artifacts
and supporting assets across eight Knowledge families. Its directory names preserve
workflow roles; they do not confer SymK authority.

The governing interpretation is
[`SYMK-KB-001 — Imported Source Authority Boundary`](../00_GOVERNANCE/SYMK-KB-001_IMPORTED_SOURCE_AUTHORITY_BOUNDARY_v0.1.md).
In particular, text inside `Sources/` that calls itself canonical, normative,
mandatory, Stable or production-blocking remains a source claim until an explicit
governed disposition accepts an exact object and scope.

## Families

1. Architectural Decisions
2. Concept Dossiers
3. Methodology
4. Reference Models
5. Research
6. Standards
7. Vocabulary
8. White Paper

Each family uses the same intended layout:

- `Sources/` — imported or recovered evidence;
- `Curation/` — assessment, lineage, decisions and open questions;
- `Canonical/` — governed family artifacts only when supported by an explicit
  disposition and canonical registration; and
- `Assets/` — supporting resources without authority by placement.

Many curation and canonical files remain placeholders. A placeholder is not a
decision, an accepted artifact or an indication that curation is complete.
