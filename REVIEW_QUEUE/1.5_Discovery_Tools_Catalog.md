# Discovery Tools Catalog

_Phase 1 — Discovery_  
_Scope: META (SymK)_

## 1. Purpose

This catalog lists the **standard tools and assets** that support PLC_1 (Discovery) at the META level:

- Document templates,
- Checklists / canvases,
- (Later) matrices, AI prompt packs, simple scripts.

Each project instance (IaaC, LexBrain, etc.) can:

- Reuse tools as-is,
- Copy them into its own repo,
- Extend the catalog with project-specific variants.

This file is intentionally **minimal** and will grow as new tools are proven useful.

---

## 2. How to read this catalog

Each entry includes:

- **ID** – Stable identifier for the tool.  
- **Phase** – Which PLC_1 step it primarily supports (1.1, 1.2, 1.3, 1.4).  
- **Kind** – `template`, `schema`, `prompt_pack`, `matrix`, etc.  
- **Name** – Human-readable label.  
- **Purpose** – What the tool is for.  
- **Location** – Path in the SymK META tree.  
- **Status** – `available` (exists now) or `planned` (not yet created).

## 5. Maintenance Rules

- New tools **must** be added here with:
  - A stable **ID**,
  - The correct **phase** and **kind**,
  - A short, honest **purpose**,
  - The real **location** once the file exists,
  - `Status = available`.
- Deprecated tools should:
  - Stay listed but be marked as `Status = deprecated`, with a note in the purpose.

This catalog is the **single source of truth** for “what META tools exist for Discovery” in the SymK PLC.
