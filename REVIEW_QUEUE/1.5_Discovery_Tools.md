# 1.5 Discovery Tools

_Phase 1 — Discovery_

## 1. Purpose / Objective

Define and maintain the **set of tools and assets** that support PLC_1 (Discovery):

- Templates and checklists,
- Scoring matrices and canvases,
- AI prompt packs,
- Simple scripts or dashboards,

so that every project instance (IaaC, LexBrain, etc.) can **run Discovery faster and with less chaos**, instead of reinventing the machinery every time.

1.5 answers:

> “What tools do we have to *run* 1.1–1.4 well, and where are they?”

---

## 2. Description

This node operates at two levels:

1. **META (SymK)**  
   - Defines and documents the **standard Discovery toolkit**, grouped by PLC_1 tasks:
     - Product vision,
     - Market research,
     - Stakeholder mapping,
     - Discovery methodologies.

2. **Project-level usage (per product PLC)**  
   - Each project chooses which tools it will actually use, and may copy/adapt them into its own repo.
   - 1.5 does *not* force usage; it makes options explicit and discoverable.

1.5 is **not** about methods themselves (that’s 1.4), and **not** about logging events (the log is just one optional tool).  
It is about the **concrete artefacts and utilities** that help those methods happen.

## 4. Outcomes

At the **META level (SymK)**, 1.5 must produce:

- **[required]**  
  `type=doc, ref=PLC/1_Discovery/1.5_Discovery_Tools/discovery_tools_catalog.md`  
  A human-readable catalogue of:

  - Tool name  
  - Purpose  
  - Which PLC_1 step(s) it supports (1.1 / 1.2 / 1.3 / 1.4)  
  - Location (path/URL)  
  - Notes (limitations, when to prefer/not use)

- **[optional]**  
  `type=data, ref=PLC/1_Discovery/1.5_Discovery_Tools/discovery_tools_index.json`  
  A machine-readable index for automation, e.g.:

  ```json
  {
    "tools": [
      {
        "id": "vision_canvas_v1",
        "phase": "1.1",
        "kind": "template",
        "path": "PLC/1_Discovery/1.5_Discovery_Tools/templates/product_vision_canvas.md"
      }
    ]
  }
  ```

Examples of tools that may be listed:

- `templates/product_vision_template.md`
- `templates/market_research_grid.md`
- `templates/stakeholder_map_canvas.md`
- `matrices/swot_matrix_iaac.xlsx`
- `matrices/segment_scoring_sheet.xlsx`
- `ai_prompts/plc_1_vision.prompts.md`
- `ai_prompts/plc_1_market_research.prompts.md`

For **project instances** (outside SymK), 1.5 may generate:

- A subset of the catalog copied or referenced into `<PROJECT>/PLC/1_Discovery/1.5_Discovery_Tools/…`, listing which tools that project actually uses.

## 5. Tools / Methodology

### How we maintain the toolkit (META side)

- Periodic **toolbox review**:
  - Add new tools when a project proves them useful.
  - Deprecate tools that create noise or are never used.

- **Versioned templates**:
  - Major changes to key templates (e.g., product_vision_template) should be versioned and tagged.

- **Minimal friction**:
  - Prefer Markdown, simple spreadsheets, and plain-text AI prompt packs over heavyweight systems.

---

## 6. AI Support / Symbiotic Role

### Roles

- **tool_recommender**  
  Suggest which tools from the catalog best fit a project’s context (based on 1.1–1.3).

- **tool_explainer**  
  Turn a raw template into an understandable “how to use this” explanation for humans.

- **tool_customizer**  
  Adapt a generic template to a specific project (e.g., tailor stakeholder canvas for LegalTech vs AWS partners).

### Prompt contracts (examples)

- `plc.1.5.list_tools`  
  - Input: current catalog + new templates from projects.  
  - Output: updated `discovery_tools_catalog.md`.

- `plc.1.5.recommend_tools`  
  - Input: a project’s 1.1/1.2/1.3 docs.  
  - Output: a suggested subset of tools to use, with rationale.

### Input context (AI)

- `doc: PLC/1_Discovery/1.1_Product_Vision/…`  
- `doc: PLC/1_Discovery/1.2_Market_Research/…`  
- `doc: PLC/1_Discovery/1.3_Stakeholder_Map/…`  
- `doc: PLC/1_Discovery/1.4_Discovery_Methodologies/…`  
- `doc: PLC/1_Discovery/1.5_Discovery_Tools/discovery_tools_catalog.md`

### Expected outputs (AI-assisted)

- Updated `discovery_tools_catalog.md` and, optionally, `discovery_tools_index.json`.
- Project-specific recommendations and customized copies of templates in each project repo.
