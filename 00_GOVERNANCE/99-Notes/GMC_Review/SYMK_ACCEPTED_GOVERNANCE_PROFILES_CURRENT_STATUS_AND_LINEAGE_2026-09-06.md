## 3. Decision-time clauses

The accepted objects are immutable evidence of decisions made at different times.
Therefore:

- Package A's statement that its acceptance did not accept Packages B–D describes
  the non-effects of the Package A decision. Packages B–D were accepted later by
  separate records.
- Package B's statement that Packages C and D remained unaccepted describes the
  state at the Package B decision. They were accepted later by separate records.
- Package C's statement that Package D remained unaccepted describes the state at
  the Package C decision. Package D was accepted later by its own record.

Those clauses remain true as decision-boundary statements: no earlier acceptance
automatically transferred to a later package. They must not be read as the current
status of the later objects.

## 5. Reading and citation rule

For current status, cite the relevant acceptance record and this note. For the exact
substantive rule, cite the immutable accepted object. For historical reasoning, cite
the predecessor proposal or evaluation artifact as applicable.

Any substantive correction requires a new version, a new exact-object hash and a
new acceptance decision. This note cannot perform that correction.

## 6. Non-effects

This note does not:

- change any accepted formulation or object hash;
- transfer acceptance among packages or methods;
- settle an open dissent or extension question;
- create a new policy, standard, constitutional rule or derived-project adoption;
- issue execution authority; or
- establish that the accepted set is complete or optimal.
