# SymK External Problem-Solving Handoff Interface Proposal v0.1

**Status:** Proposal; not accepted and not activated  
**Date:** 2026-09-08

## 1. Purpose

Define the smallest interface needed for a SymK mediation route to obtain external
problem-framing, search or investment analysis without absorbing the external
method into SymK.

## 2. Outbound record

When relevant and proportionate, the handoff identifies:

- mediation engagement and route;
- exact question or candidate problem Representation;
- caller framing and material alternative Representations;
- participants, affected parties and known absent perspectives;
- evidence, counterevidence, uncertainty and provenance;
- Context, Scope, time horizon and constraints;
- Authority and Responsibility boundaries;
- preserved disagreement and non-negotiable conditions;
- context-portability constraints; and
- requested output and stopping point.

Unknown fields remain unknown. The external method may request clarification,
narrow its claim or return the matter without analysis.

## 3. Inbound contribution

The external method should return:

- versioned frame candidates;
- observations separated from interpretations and recommendations;
- action, inquiry, monitoring and inaction alternatives;
- evidence used, missing evidence and sensitivity to disputed assumptions;
- problem complexity kept distinct from method-induced complexity;
- present capability and context feasibility;
- total-burden and investment-worth reasoning;
- the smallest recommended next commitment, if any;
- expected evidence and stop/reconsideration conditions; and
- assessor, competence boundary, limitations and decision status.

The result is a Representation and Contribution, not a decision or Authority.

## 4. Mandatory return to mediation

The external method must not silently resolve:

- excluded or newly identified affected parties;
- incompatible problem frames;
- standing, Authority or Responsibility disputes;
- value conflicts represented as technical optimization;
- material context loss;
- disagreement that a scoring or aggregation step would erase; or
- a requested action outside the admitted engagement.

Those conditions return to the applicable SymK route or competent external
authority.

## 5. Non-effects

This proposal does not accept an interface, select the `ProblemSolving` project,
activate a route, validate an external method, assign a role, transfer Authority,
create a universal schema or authorize consequential action.
