# 2.2 Evidence Manifest — Template

**Status:** Inert template; no hashes are asserted  
**Purpose:** Define the fields required for a formal-stage integrity manifest.

For every controlled artifact record: relative path, SHA-256, byte count, line/page count where applicable, evidence identifier, producing stream, source/review/output role, mutability status and verification date.

The formal manifest must include the opening control, frozen accepted inputs, every stream report and structured evidence table, the exact Proposed Candidate, checkpoint record, registers, affected-artifact map and any executable verification instructions. Historical, Proposed, Candidate and accepted artifacts must be distinguishable.

No entry is created by this template.
