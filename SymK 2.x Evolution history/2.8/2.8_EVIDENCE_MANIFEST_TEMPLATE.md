# SymK 2.8 Evidence Manifest — Template

**Status:** Inert template; no hashes are asserted

A formal manifest must record relative path, SHA-256, byte count, line/page count where applicable, evidence identifier, producing work package, source/review/output role, authority status, mutability status and verification date.

It must include the opening control, frozen accepted inputs, work-package evidence, exact decision/checkpoint object, registers, affected-artifact/project records and reproducible verification instructions.

No evidence, authority or status transition is created by this template.
