# Program Registers

## Required registers

Each stage maintains:

- **Decision Register:** every material proposed or accepted conclusion.
- **Evidence Register:** sources, observations, counterexamples, and compatibility evidence.
- **Tension Register:** enduring opposing requirements that must remain visible.
- **Deferred Questions:** questions routed to later stages.
- **Change Log:** changes to the evolution package and affected canonical artifacts.
- **Stage Summary:** scope, decisions, dissent, remaining risks, and gate result.

## Identifier conventions

- Decisions: `SYMK-2X-DR-nnn`
- Evidence: `SYMK-2X-EV-nnn`
- Tensions: `SYMK-2X-TN-nnn`
- Deferred questions: `SYMK-2X-DQ-nnn`
- Changes: `SYMK-2X-CH-nnn`

Identifiers are never reused. Rejected and superseded records remain in sequence.
