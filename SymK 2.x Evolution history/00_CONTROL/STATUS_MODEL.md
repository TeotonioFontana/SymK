# Evolution Status Model

| Status | Meaning | Normative effect |
|---|---|---|
| Observed | Recovered from history or current practice | Evidence only |
| Questioned | Formally placed under examination | None |
| Proposed | A reasoned position is available for review | None |
| Contested | Material alternatives or objections remain active | None |
| Deferred | Assigned explicitly to a later stage | None in current stage |
| Stage-Accepted | Accepted as the baseline needed to continue the 2.x program | Provisional program authority |
| Ratified | Approved through the constituted SymK constitutional authority | Normative at its declared level |
| Superseded | Replaced explicitly with lineage preserved | Historical authority only |
| Retired | No longer active and without a successor obligation | Historical record only |

“Canonical” is not a maturity status. It describes the governed location or selected representation of an artifact. Every canonical artifact must also declare maturity and normative authority.
