# 2.3 Evidence Manifest — Template

**Status:** Inert template; no hashes are asserted  
**Purpose:** Define the fields required for formal 2.3 integrity control.

For every controlled artifact record: relative path, SHA-256, byte count, line/page count where applicable, evidence identifier, producing stream, source/review/output role, authority status, mutability status and verification date.

The formal manifest must include the opening control, transitional-authority source, exact 2.2 Candidate, every work-package report and structured evidence table, 2.3A mechanism and checkpoint, exact constituted-authority record, 2.3R deliberation and decision, registers, migration/impact records and verification instructions.

No authority, status transition or manifest entry is created by this template.
