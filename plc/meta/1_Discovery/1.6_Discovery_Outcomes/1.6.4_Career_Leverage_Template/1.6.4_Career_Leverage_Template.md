# PLC_META — 1.6.4 Career Leverage Template

## Purpose

Provide a standard way to answer:

> “Is this product good to help the architect/founder find a job?”

This is about **career leverage**, not just product success.

## Setup

Each product instance must first state its **target roles**, e.g.:

- Cloud / AWS Architect  
- Backend / Infra Architect  
- AI-assisted tooling engineer  
- Product / Tech Lead in a given domain

## Axes (0–3 each)

Evaluate the product instance on:

1. **Relevance to job requirements**
   - Overlap between what the product demonstrates and what target job descriptions ask for.

2. **Signal strength**
   - Does the product look like a **real system** (architecture, robustness, real-world use), or a toy demo?

3. **Story quality**
   - Can you tell a concise, compelling “I led X” story based on this product?

Score each 0–3, then sum (0–9) and map to labels:

- **0–3** → Mostly irrelevant
- **4–6** → Helpful but indirect
- **7–9** → Strong signal

## Product-specific file requirements

Each `1.6.4_*.md` file must:

1. List target roles explicitly.
2. Show a short table or bullet list with the three axes and scores.
3. Provide a **sentence-level answer**, e.g.:

> “Career leverage: Strong (8/9). This project demonstrates multi-account AWS architecture, DR automation, and compliance evidence, which map directly to the skills listed in the target roles.”
